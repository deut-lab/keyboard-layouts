# Розкладки клавіатури RuUa та EnDe для Windows

[English](README.md) · [Deutsch](README.de.md) · **Українська** · [Русский](README.ru.md)

Дві розкладки, щоб писати російською, українською, німецькою та англійською без зайвих перемикань.

- **RuUa**: російська розкладка ЙЦУКЕН, у якій є й українські літери ґ, і, ї, є.
- **EnDe**: англійська розкладка QWERTY, у якій є й німецькі літери ä, ö, ü, ß.

Літери на звичних місцях, а додаткові знаки набираються з **правим Alt**.

**Зображення клавіатур і пояснення, чому знаки стоять саме так:** https://deut-lab.github.io/keyboard-layouts/uk/

## Встановлення

1. Завантажте архів зі [сторінки випуску](https://github.com/deut-lab/keyboard-layouts/releases/latest): `RuUa2611.zip` або `EnDe2611.zip`.
2. Розпакуйте його й запустіть `setup.exe`. Погодьтеся, коли Windows попросить права адміністратора.
3. Вийдіть з облікового запису Windows і увійдіть знову.
4. Відкрийте «Параметри», потім «Час і мова» та «Мова й регіон». Біля потрібної мови натисніть «…», потім «Параметри мови» та «Додати клавіатуру» й виберіть **Russia-Ua 20261117** (для російської) або **LAT-DEU 20261117** (для англійської).

Якщо Windows пише «Windows захистила ваш ПК», натисніть «Докладніше» і «Усе одно запустити». Так буває, бо в інсталятора немає платного цифрового підпису.

На комп’ютерах із процесором ARM (Snapdragon, Surface Pro X) розкладки не працюють.

Щоб видалити розкладку, відкрийте «Параметри», потім «Програми» та «Інстальовані програми», знайдіть її назву й натисніть «Видалити».
