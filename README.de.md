# Tastaturlayouts RuUa und EnDe für Windows

[English](README.md) · **Deutsch** · [Українська](README.uk.md) · [Русский](README.ru.md)

Zwei Layouts, um Russisch, Ukrainisch, Deutsch und Englisch ohne zusätzliches Umschalten zu schreiben.

- **RuUa**: das russische Layout ЙЦУКЕН mit den ukrainischen Buchstaben ґ, і, ї, є.
- **EnDe**: das englische Layout QWERTY mit den deutschen Buchstaben ä, ö, ü, ß.

Die Buchstaben bleiben, wo Sie sie gewohnt sind; zusätzliche Zeichen tippen Sie mit der **rechten Alt-Taste** (AltGr).

**Tastaturbilder und warum alles so liegt:** https://deut-lab.github.io/keyboard-layouts/de/

## Installation

1. Laden Sie ein Archiv von der [Release-Seite](https://github.com/deut-lab/keyboard-layouts/releases/latest) herunter: `RuUa2611.zip` oder `EnDe2611.zip`.
2. Entpacken Sie es und starten Sie `setup.exe`. Erlauben Sie die Administratorrechte, wenn Windows fragt.
3. Melden Sie sich bei Windows ab und wieder an.
4. Öffnen Sie „Einstellungen“, dann „Zeit und Sprache“ und „Sprache und Region“. Neben Ihrer Sprache „…“, dann „Sprachoptionen“ und „Tastatur hinzufügen“, und wählen Sie **Russia-Ua 20261117** (für Russisch) oder **LAT-DEU 20261117** (für Englisch).

Wenn Windows „Der Computer wurde durch Windows geschützt“ meldet, klicken Sie auf „Weitere Informationen“ und „Trotzdem ausführen“. Die Meldung erscheint, weil der Installer keine kostenpflichtige digitale Signatur hat.

Auf Computern mit ARM-Prozessor (Snapdragon, Surface Pro X) funktionieren die Layouts nicht.

Zum Entfernen öffnen Sie „Einstellungen“, dann „Apps“ und „Installierte Apps“, suchen den Namen des Layouts und klicken auf „Deinstallieren“.
